# Erebos

**Erebos** is the darkness that hasn’t yet decided what it wants to become.  
Inspired by this concept, this project aims to simulate a variety of services, providing a flexible and experimental environment for testing and development.

## Overview

Erebos is a Go-based simulation framework designed to mimic the behavior of multiple services. It allows developers to experiment, test integrations, and explore service interactions without relying on live systems.

## Features

- Simulate multiple services concurrently.
- Configurable service behaviors and responses.
- Lightweight and easy to deploy.
- Ideal for testing, development, and experimentation.
